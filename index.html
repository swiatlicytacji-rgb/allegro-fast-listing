Allegro Fast Listing

Wersja aplikacji: 1.0.0

Allegro Fast Listing to aplikacja wspierająca szybkie przygotowywanie, tworzenie i publikowanie ofert sprzedażowych na Allegro z wykorzystaniem Allegro REST API.

Funkcje

  • autoryzacja konta Allegro przez OAuth 2.0,
  • odczyt, tworzenie i edycja ofert,
  • publikowanie przygotowanych ofert,
  • wyszukiwanie produktów w Katalogu Produktów Allegro,
  • obsługa zdjęć produktów,
  • rozpoznawanie produktu na podstawie zdjęcia lub kodu EAN/GTIN,
  • planowana obsługa przesyłek.

Bezpieczeństwo

Logowanie użytkownika odbywa się po stronie Allegro. Aplikacja nie wymaga przekazywania hasła do konta Allegro. Dostęp do API realizowany jest z wykorzystaniem mechanizmu OAuth.

Środowisko MVP

Wersja 1.0.0 jest rozwijana i testowana jako aplikacja MVP. Lokalny adres zwrotny OAuth może korzystać z http://localhost:3000/oauth/callback.

Allegro REST API

Aplikacja korzysta z oficjalnego Allegro REST API w zakresie uprawnień przyznanych przez użytkownika.
